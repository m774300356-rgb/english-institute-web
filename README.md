# معهدي — موقع تعلم إنجليزي مستقل (نسخة أولية بدون دفع)

هذا مشروع Next.js كامل، مبني عشان تنشره كموقع حقيقي على الإنترنت، وتستخدمه أو
تشاركه مع ناس آخرين. الذكاء الاصطناعي يشتغل من سيرفرك أنت (عبر مفتاح Anthropic
API الخاص فيك)، مو من حساب Claude الشخصي حق كل زائر — يعني **أنت اللي تدفع
تكلفة الاستخدام**، وهذا مهم تعرفه قبل ما تشارك الرابط مع عدد كبير من الناس.

## وش فيه؟

- اختيار لغة الشرح (عربي/إنجليزي حالياً، وتقدر تضيف لغات لاحقاً في `lib/i18n.js`)
- اختبار تحديد مستوى قبل البداية (مبتدئ/متوسط/متقدم)
- درس يومي بمفردات مناسبة لمستوى المستخدم
- قراءة تفاعلية: تضغط على أي كلمة يطلع معناها فوراً
- تمارين مراجعة للكلمات المحفوظة
- محادثة نصية مع الذكاء الاصطناعي لممارسة التحدث
- **🪞 وضع المرآة**: تتكلم بالمايك، المتصفح يتعرف على كلامك، ويعطيك درجة نطق
  فورية + نصيحة من الذكاء الاصطناعي — بدون أي تكلفة سيرفر لأنه يستخدم خاصية
  التعرف على الكلام المدمجة بالمتصفح.
- **📖 القصة المستمرة**: قصة أصلية تتقدم فصل بفصل، لكن الفصل الجديد ما يفتح
  إلا بعد ما تخلص مراجعة اليوم — يشجعك ترجع كل يوم.

بيانات كل زائر (كلماته، تقدمه) محفوظة بمتصفحه فقط (localStorage) — بدون قاعدة
بيانات لسه. هذا يعني بياناته ما تنتقل بين الأجهزة، وإذا مسح بيانات المتصفح
تروح. هذا مقصود بالنسخة الأولى لتبسيط الإطلاق — قسم "الخطوة التالية" تحت
يشرح كيف تضيف حسابات حقيقية بعدين.

## الخطوات — من الصفر للنشر

### 1. جهّز الأدوات (مرة واحدة فقط)
1. أنشئ حساب على [github.com](https://github.com) إذا ما عندك.
2. أنشئ حساب على [vercel.com](https://vercel.com) وسجّل دخول بحساب GitHub نفسه
   (بضغطة واحدة، Vercel هي شركة استضافة مجانية للمشاريع الصغيرة ومبنية خصيصاً
   لمشاريع Next.js، وهذا سبب اختيارها).
3. احصل على مفتاح Anthropic API من [console.anthropic.com](https://console.anthropic.com)
   (تحتاج تنشئ حساب هناك وتضيف بطاقة دفع لتفعيل الاستخدام — هذا مختلف عن حساب
   Claude.ai العادي).

### 2. رفع المشروع على GitHub
1. افتح [github.com/new](https://github.com/new) وأنشئ مستودع (repository) جديد،
   سمّه مثلاً `english-institute-web`. اختر "Private" إذا تبي تخليه خاص بالبداية.
2. نزّل الملف المرفق (zip) وفكّه على جهازك.
3. بالمستودع الجديد على GitHub، بيطلع لك زر "uploading an existing file" —
   اسحب كل الملفات والمجلدات اللي فكيتها وارفعها، واضغط "Commit changes".

### 3. النشر على Vercel
1. من لوحة Vercel، اضغط "Add New" → "Project".
2. اختر المستودع اللي رفعته (`english-institute-web`).
3. Vercel بيتعرف على المشروع كـ Next.js تلقائياً — لا تغيّر أي إعداد.
4. قبل الضغط على Deploy، افتح قسم "Environment Variables" وأضف:
   - الاسم: `ANTHROPIC_API_KEY`
   - القيمة: مفتاحك من console.anthropic.com
5. اضغط "Deploy" وانتظر دقيقة أو دقيقتين.
6. بعد ما يخلص، بيعطيك رابط مثل `english-institute-web.vercel.app` — هذا
   موقعك الحي، تقدر تفتحه من أي جهاز وتشاركه.

### 4. كل تحديث بعدين
أي تعديل تسويه على الملفات ورفعته على GitHub (Commit)، Vercel ينشره تلقائياً
بدون ما تسوي شي إضافي.

## تنبيه مهم عن التكلفة

بما إنه ما فيه قاعدة بيانات أو حد أقصى للاستخدام بهذي النسخة، لو شاركت الرابط
مع عدد كبير من الناس، فاتورة Anthropic API ممكن تكبر بسرعة. لأي استخدام تجاري
حقيقي أو عدد مستخدمين أكبر، لازم تضيف:
- **نظام حسابات + قاعدة بيانات** (اقترح [Supabase](https://supabase.com) —
  مجاني للمشاريع الصغيرة، وفيه نظام تسجيل دخول جاهز).
- **حد أقصى استخدام يومي لكل مستخدم** (تتحقق منه بالسيرفر قبل كل طلب للذكاء
  الاصطناعي).
- **نظام دفع** (اقترح [Stripe](https://stripe.com) للاشتراكات الشهرية).

قولي أي وقت تبي تبدأ بهذي الخطوة وأساعدك فيها خطوة بخطوة.

## هيكلة الملفات

```
app/
  page.js              → الصفحة الأولى (توجيه تلقائي)
  onboarding/page.js   → اختيار اللغة + اختبار تحديد المستوى
  dashboard/page.js    → التطبيق الرئيسي بكل التبويبات
  api/ai/route.js      → الاتصال بالذكاء الاصطناعي (يشتغل على السيرفر فقط)
  globals.css          → التصميم العام
lib/
  i18n.js              → نصوص الواجهة بكل اللغات
  storage.js           → حفظ بيانات المستخدم بمتصفحه
```

لإضافة لغة جديدة: افتح `lib/i18n.js` وأضف كتلة جديدة بنفس شكل `ar ` أو `en`.
